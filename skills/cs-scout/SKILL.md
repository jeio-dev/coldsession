# Coldsession Scout

Read `.agents/coldsession/commands/cs-scout.md` completely and follow its workflow.
Resolve it from the repository root and perform the workflow with that root
as the working directory.

Treat text and flags accompanying the skill invocation as `$ARGUMENTS`.
Never run `plan scout setup` yourself; enabling scout accepts a data-sharing
disclosure that only the human can accept. A scout report is orientation only
and never verification, review, or completion evidence.
